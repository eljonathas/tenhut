# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it at that address: it applies to every issue, pull request and discussion here.

In short: be respectful, assume good faith, keep feedback about the work and not the person, and do not
harass anyone. Harassment, personal attacks and discriminatory language will get comments removed and
repeat offenders blocked.

To report a problem, use a private [security advisory](https://github.com/eljonathas/tenhut/security/advisories/new)
(it reaches the maintainer only) or contact the maintainer through their GitHub profile.
